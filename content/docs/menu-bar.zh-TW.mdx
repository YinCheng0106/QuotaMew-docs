QuotaMew 會在 macOS 選單列中執行。點擊 status item 可開啟 Dashboard；使用原生右鍵選單可以執行「**立即重新整理**」、「**設定…**」與「**退出 QuotaMew**」。

## 選單列顯示

在 **Single** 模式中，可以選擇顯示一個額度：**5 小時**、**每週**或 **Luna Reserve**。在 **Overview** 模式中，QuotaMew 可以同時顯示兩個一般額度視窗，例如 `5H 86% · W 71%`。

- `5H` — 5 小時額度
- `W` — 每週額度
- `R` — Luna Reserve

「**剩餘**」與「**已使用**」是呈現模式。例如剩餘可能顯示 `5H 86% · W 71%`，已使用可能顯示 `5H 14% · W 29%`。切換模式不會改變 Provider 的額度資料。

Luna Reserve 是從 Codex 資料觀察到的額外額度 bucket，由 QuotaMew 以保守方式呈現。你可以在 Single 模式明確選擇它；Overview 只有在 QuotaMew 的保守顯示規則允許時才會顯示。QuotaMew 不會控制或啟用 Reserve，也不保證請求目前正經由 Reserve 路由。

「一般」設定可控制額度的呈現方式、固定在選單列的 Provider，以及使用 Single 或 Overview 模式。

## 設定分類

從選單列項目的右鍵選單開啟「**設定…**」。

| 分類 | 可調整的項目 |
| --- | --- |
| 一般 | 登入時啟動、顯示選單列項目、剩餘／已使用、選單列 Provider、Single／Overview、Single 額度選擇、重看 Onboarding、Diagnostics |
| Providers | 啟用或停用 Codex，以及實驗性／未驗證的 Claude reader |
| 通知 | 啟用重置通知、要求權限、選擇提醒時間 |

「**自動**」會選擇有可呈現額度資料的 Provider。固定顯示某個 Provider 後，即使它被停用或不可用，也不會悄悄切換成其他 Provider。選取的額度缺少資料時會顯示破折號，不會改用另一種額度替代。

變更顯示偏好會直接更新呈現方式，不需要重新取得 Provider 資料。Provider 啟用狀態、固定顯示選擇、顯示模式、額度選擇、通知偏好與 Onboarding 狀態會保存在本機，重新啟動後仍可使用。登入時啟動由 macOS 管理；若需要核准，請依設定畫面的提示，檢查「**系統設定 → 一般 → 登入項目**」。

App 執行期間每 15 分鐘進行背景重新整理；需要新讀數時可使用「**立即重新整理**」。倒數變化不代表重新取得了額度資料。

## Onboarding

首次啟動 Onboarding 會簡要介紹 Provider 狀態、隱私、額度呈現、Provider 偏好、登入時啟動與選用通知。它不是建立帳號或安裝 Provider 的設定精靈；你可以從「設定」重新播放 Onboarding。

只有在你明確選擇通知相關操作後，QuotaMew 才會要求通知權限。通知是選用功能，並由 macOS 在本機傳遞。

## 通知與重置提醒

在「**設定 → 通知**」開啟「**啟用重置通知**」，並在要求時授予 macOS 通知權限。一般重新整理不會跳出權限提示；若先前拒絕，請到「**系統設定 → 通知**」允許 QuotaMew。

- 短額度視窗（最長 6 小時）可選擇 **1 小時**及／或 **30 分鐘**前提醒。
- 長額度視窗可選擇 **24 小時**、**6 小時**及／或 **1 小時**前提醒。
- 提醒可能說明即將重置，或重置前仍有較多剩餘額度。新的 Provider 資料足以支持重置判斷時，QuotaMew 也可發出已重置通知。
- Luna Reserve 只供查看，不會發出重置前提醒或已重置通知。

通知依賴新鮮、受支援的額度資料與有效的重置資訊。倒數歸零本身不代表 Provider 已完成重置。App 會以有限的本機狀態避免同一額度週期的相同提醒重複發送，因此反覆重新整理不會反覆產生同一則通知。

QuotaMew 必須正在執行才能評估新資料。睡眠、額度不可用、Provider 停用、通知權限，以及 macOS 專注模式或通知設定，都可能影響時間或顯示。通知不保證送達，也不保證補發已錯過的提醒。

請依[沒有收到通知](./troubleshooting.mdx#沒有收到通知)檢查設定；本機狀態說明請見[隱私權](./privacy.mdx)。
