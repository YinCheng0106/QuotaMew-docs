If QuotaMew is not working as expected, find the issue that most closely matches what you are experiencing and follow the suggested steps.

<Callout type="info" title="Before you start">

Make sure you are using the latest available version of QuotaMew.

If you recently installed or updated QuotaMew, quitting and reopening the app is also a good first step.

</Callout>

## QuotaMew cannot be opened

**Symptom**

macOS prevents QuotaMew from opening after you install or update the app.

**Try this**

If macOS displays a security warning, follow the [First Launch guide](./first-launch.mdx).

The current Release Candidate is Apple Development signed, but not Developer ID signed or notarized, so macOS may require additional approval before allowing QuotaMew to run.

**Still not working?**

Make sure QuotaMew was moved to the **Applications** folder and try opening it again from there.

## QuotaMew does not appear in the menu bar

**Symptom**

QuotaMew appears to be running, but its icon is not visible in the macOS menu bar.

**Try this**

1. Quit QuotaMew and open it again from the **Applications** folder.
2. Check whether QuotaMew is allowed to appear in the menu bar in macOS settings.
3. If your menu bar contains many items, make sure the QuotaMew icon is not hidden or unavailable because of limited space.

**Still not working?**

Restart QuotaMew and check whether the issue happens again.

If the problem continues, report the issue and include your macOS version and QuotaMew version.

## A provider appears disconnected

**Symptom**

A provider in QuotaMew shows a disconnected or unavailable state.

**Try this**

1. Make sure the corresponding provider application or environment is installed and available.
2. Open the provider application if required.
3. Return to QuotaMew and refresh the usage information.
4. Check your provider settings in QuotaMew.

**Still not working?**

Quit and reopen QuotaMew.

If the provider remains disconnected, include the provider name and the state shown by QuotaMew when reporting the issue.

## Usage information is not refreshing

**Symptom**

The usage information displayed by QuotaMew appears outdated or does not change after a refresh.

**Try this**

1. Make sure the provider is connected and available.
2. Use the refresh action in QuotaMew.
3. Wait briefly and check the usage information again.
4. Quit and reopen QuotaMew if the issue continues.

**Still not working?**

When reporting the issue, include:

- The affected provider
- Your QuotaMew version
- Your macOS version
- What QuotaMew displayed before and after refreshing

## Still need help?

If the problem continues, report it through the QuotaMew GitHub issue tracker.

Please include as much of the following information as possible:

- QuotaMew version
- macOS version
- Affected provider
- What you expected to happen
- What actually happened
- Steps that reproduce the issue
- Relevant screenshots, if available

<Callout type="info" title="Do not include sensitive information">

Before posting logs or screenshots publicly, check that they do not contain personal information, credentials, access tokens, or other sensitive data.

</Callout>
