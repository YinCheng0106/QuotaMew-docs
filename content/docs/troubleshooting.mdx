If QuotaPulse is not working as expected, find the issue that most closely matches what you are experiencing and follow the suggested steps.

<Callout type="info" title="Before you start">

Make sure you are using the latest available version of QuotaPulse.

If you recently installed or updated QuotaPulse, quitting and reopening the app is also a good first step.

</Callout>

## QuotaPulse cannot be opened

**Symptom**

macOS prevents QuotaPulse from opening after you install or update the app.

**Try this**

If macOS displays a security warning, follow the [First Launch guide](./first-launch.mdx).

The current beta is not yet signed and notarized with an Apple Developer ID, so macOS may require additional approval before allowing QuotaPulse to run.

**Still not working?**

Make sure QuotaPulse was moved to the **Applications** folder and try opening it again from there.

## QuotaPulse does not appear in the menu bar

**Symptom**

QuotaPulse appears to be running, but its icon is not visible in the macOS menu bar.

**Try this**

1. Quit QuotaPulse and open it again from the **Applications** folder.
2. Check whether QuotaPulse is allowed to appear in the menu bar in macOS settings.
3. If your menu bar contains many items, make sure the QuotaPulse icon is not hidden or unavailable because of limited space.

**Still not working?**

Restart QuotaPulse and check whether the issue happens again.

If the problem continues, report the issue and include your macOS version and QuotaPulse version.

## A provider appears disconnected

**Symptom**

A provider in QuotaPulse shows a disconnected or unavailable state.

**Try this**

1. Make sure the corresponding provider application or environment is installed and available.
2. Open the provider application if required.
3. Return to QuotaPulse and refresh the usage information.
4. Check your provider settings in QuotaPulse.

**Still not working?**

Quit and reopen QuotaPulse.

If the provider remains disconnected, include the provider name and the state shown by QuotaPulse when reporting the issue.

## Usage information is not refreshing

**Symptom**

The usage information displayed by QuotaPulse appears outdated or does not change after a refresh.

**Try this**

1. Make sure the provider is connected and available.
2. Use the refresh action in QuotaPulse.
3. Wait briefly and check the usage information again.
4. Quit and reopen QuotaPulse if the issue continues.

**Still not working?**

When reporting the issue, include:

- The affected provider
- Your QuotaPulse version
- Your macOS version
- What QuotaPulse displayed before and after refreshing

## Still need help?

If the problem continues, report it through the QuotaPulse GitHub issue tracker.

Please include as much of the following information as possible:

- QuotaPulse version
- macOS version
- Affected provider
- What you expected to happen
- What actually happened
- Steps that reproduce the issue
- Relevant screenshots, if available

<Callout type="info" title="Do not include sensitive information">

Before posting logs or screenshots publicly, check that they do not contain personal information, credentials, access tokens, or other sensitive data.

</Callout>
