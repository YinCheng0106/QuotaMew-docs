## General

<Accordions>

<Accordion title="Is QuotaMew free and open source?" id="free-and-open-source">

Yes. QuotaMew is free and open source and is distributed under the MIT License.

</Accordion>

<Accordion title="Do I need an OpenAI API key?" id="api-key">

No separate OpenAI API key is required for the supported Codex integration.

QuotaMew communicates with the compatible Codex runtime installed on your Mac. Codex remains responsible for its own authentication and provider communication.

</Accordion>

<Accordion title="Is QuotaMew affiliated with OpenAI or Anthropic?" id="affiliation">

QuotaMew is an independent open-source project and is not an official product of OpenAI or Anthropic.

OpenAI, ChatGPT, Codex, Anthropic, Claude, and other product names and trademarks belong to their respective owners.

</Accordion>

</Accordions>

## Installation & Updates

<Accordions>

<Accordion title="Why does macOS show a security warning?" id="security-warning">

The current beta distribution is not yet signed and notarized with an Apple Developer ID.

Because of this, macOS may require additional approval before allowing QuotaMew to open.

See the [First Launch guide](./first-launch.mdx) for the recommended steps.

</Accordion>

<Accordion title="Do I need to uninstall the old version before updating?" id="uninstall-before-update">

No.

Quit the currently running version of QuotaMew, open the new disk image, and drag QuotaMew into the Applications folder.

When Finder asks whether you want to replace the existing application, select **Replace**.

See the [Updating guide](./updating.mdx) for the complete process.

</Accordion>

<Accordion title="Will updating QuotaMew remove my settings?" id="settings-after-update">

Your existing settings should normally remain available when you replace QuotaMew with a newer version.

QuotaMew stores application preferences locally, and replacing the application itself does not normally remove those preferences.

</Accordion>

</Accordions>

## Privacy

<Accordions>

<Accordion title="Does QuotaMew upload my prompts or coding activity?" id="coding-activity">

QuotaMew is designed not to intentionally upload your prompts, conversations, source code, coding history, authentication credentials, or provider session contents.

Usage information needed by QuotaMew is processed locally on your Mac.

For more details, see [Privacy](./privacy.mdx).

</Accordion>

<Accordion title="Does QuotaMew read my Codex credentials?" id="credentials">

QuotaMew does not read or copy your Codex authentication file.

For Codex, authentication remains the responsibility of the locally installed Codex runtime.

</Accordion>

<Accordion title="Does QuotaMew use analytics or cloud sync?" id="analytics">

The current QuotaMew application does not require a QuotaMew analytics service, account, backend, or cloud sync.

Future features that change this behavior will be documented before they become part of the stable product.

</Accordion>

</Accordions>

## Compatibility

<Accordions>

<Accordion title="Which macOS versions are supported?" id="macos-support">

QuotaMew currently requires macOS 14 or later.

</Accordion>

<Accordion title="Does QuotaMew support Intel Macs?" id="intel-mac">

Intel Macs are not currently validated.

QuotaMew is currently tested primarily on Apple silicon. Intel compatibility should be treated as unverified until it has been tested and documented.

</Accordion>

<Accordion title="Which providers are supported?" id="providers">

Codex is the currently validated provider integration.

Claude Code support is implemented as an experimental and unverified integration and may require additional setup or validation.

</Accordion>

</Accordions>
