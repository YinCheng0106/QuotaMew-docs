QuotaPulse does not currently include automatic updates.

To install a newer version, download the latest disk image and replace the existing QuotaPulse application.

<Callout type="info" title="Your settings should remain available">

Replacing the QuotaPulse application normally does not remove your existing settings.

You do not need to uninstall the previous version before updating.

</Callout>

## Update QuotaPulse

<Steps>

<Step>

### Quit QuotaPulse

Before updating, quit the currently running version of QuotaPulse.

This ensures macOS can replace the application correctly.

</Step>

<Step>

### Download the latest version

Download the latest QuotaPulse `.dmg` from the official QuotaPulse website or GitHub Releases.

</Step>

<Step>

### Open the disk image

Open the downloaded QuotaPulse disk image.

</Step>

<Step>

### Move QuotaPulse to Applications

Drag **QuotaPulse** into the **Applications** folder.

Because QuotaPulse is already installed, Finder should ask whether you want to replace the existing application.

</Step>

<Step>

### Replace the existing version

Select **Replace** when Finder asks what you want to do.

This replaces the application itself without normally removing your saved preferences.

</Step>

<Step>

### Open QuotaPulse

Open QuotaPulse again from your Applications folder.

Verify that the expected version is running and that your previous settings are still available.

</Step>

</Steps>

## macOS shows a security warning again

Because the current beta is not yet signed and notarized with an Apple Developer ID, macOS may perform another security check after installing a newer version.

If macOS blocks QuotaPulse, follow the [First Launch guide](./first-launch.mdx).
