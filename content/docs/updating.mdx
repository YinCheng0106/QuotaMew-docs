QuotaMew does not currently include automatic updates.

To install a newer version, download the latest disk image and replace the existing QuotaMew application.

<Callout type="info" title="Your settings should remain available">

Replacing the QuotaMew application normally does not remove your existing settings.

You do not need to uninstall the previous version before updating.

</Callout>

## Update QuotaMew

<Steps>

<Step>

### Quit QuotaMew

Before updating, quit the currently running version of QuotaMew.

This ensures macOS can replace the application correctly.

</Step>

<Step>

### Download the latest version

Download the current `QuotaMew-v0.2.0-beta.3.dmg` from the [Beta 3 GitHub Release](https://github.com/YinCheng0106/QuotaMew/releases/tag/v0.2.0-beta.3) or the official QuotaMew website.

</Step>

<Step>

### Open the disk image

Open the downloaded QuotaMew disk image.

</Step>

<Step>

### Move QuotaMew to Applications

Drag **QuotaMew** into the **Applications** folder.

Because QuotaMew is already installed, Finder should ask whether you want to replace the existing application.

</Step>

<Step>

### Replace the existing version

Select **Replace** when Finder asks what you want to do.

This replaces the application itself without normally removing your saved preferences.

</Step>

<Step>

### Open QuotaMew

Open QuotaMew again from your Applications folder.

Verify that the expected version is running and that your previous settings are still available.

</Step>

</Steps>

## macOS shows a security warning again

Because the current beta is not yet signed and notarized with an Apple Developer ID, macOS may perform another security check after installing a newer version.

If macOS blocks QuotaMew, follow the [First Launch guide](./first-launch.mdx).
