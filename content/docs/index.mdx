QuotaMew is a lightweight native macOS menu bar app for monitoring AI coding usage and reset times.

<ImageZoom src="/images/screenshots/quotamew-dashboard.png" alt="QuotaMew macOS menu bar dashboard showing Codex 5-hour, Weekly, and Luna Reserve quota" width={460} height={557} className="mx-auto h-auto w-full max-w-[460px]" />

## What is QuotaMew?

QuotaMew keeps your AI coding usage visible directly from the macOS menu bar, so you can quickly understand your remaining quota and upcoming reset time without interrupting your workflow.

Beta 3 supports configurable Single and Overview menu bar modes. `5H` means 5-hour, `W` means Weekly, and `R` means Luna Reserve. Remaining and Used change how values are presented; they do not change provider quota data.

## Supported Providers

QuotaMew currently provides validated support for Codex.

Claude Code support is experimental and unverified.
