QuotaPulse is a lightweight native macOS menu bar app for monitoring AI coding usage and reset times.

## What is QuotaPulse?

QuotaPulse keeps your AI coding usage visible directly from the macOS menu bar, so you can quickly understand your remaining quota and upcoming reset time without interrupting your workflow.

## Supported Providers

QuotaPulse currently provides validated support for Codex.

Claude Code support is experimental and unverified.
