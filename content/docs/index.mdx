QuotaMew is a native macOS menu-bar app for monitoring AI coding quota and reset times, especially Codex.

<ImageZoom src="/images/screenshots/quotamew-dashboard.png" alt="QuotaMew macOS menu bar dashboard showing Codex 5-hour, Weekly, and Luna Reserve quota" width={460} height={557} className="mx-auto h-auto w-full max-w-[460px]" />

## What is QuotaMew?

QuotaMew keeps quota windows visible directly from the macOS menu bar, so you can check remaining limits and reset times without repeatedly opening provider interfaces.

The current public release is <StableReleaseName locale="en" />. It supports configurable Single and Overview menu bar modes. `5H` means 5-hour, `W` means Weekly, and `R` means Luna Reserve. Remaining and Used change how values are presented; they do not change provider quota data.

## Supported Providers

QuotaMew currently provides validated support for Codex.

Claude Code is **Experimental / Unverified**: its limited snapshot reader is not equivalent to Codex support. See [Providers](./providers.mdx) for prerequisites and limitations.
