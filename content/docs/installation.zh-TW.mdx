## 系統需求

安裝 QuotaPulse 前，請確認你的 Mac 符合以下需求：

- macOS 14 或更新版本

<Callout type="warn" title="Beta 版本">

QuotaPulse 目前以 Beta 版本形式提供，尚未使用 Apple Developer ID 完成簽署與公證（Notarization）。

因此，在你第一次開啟 QuotaPulse 時，macOS 可能會顯示安全性警告。

請只從 QuotaPulse 官方網站或 GitHub Repository 下載 QuotaPulse。

</Callout>

## 安裝 QuotaPulse

<Steps>

<Step>

### 下載 QuotaPulse

從 [QuotaPulse 官方下載頁面](/zh-TW/download)取得最新版本的 QuotaPulse 磁碟映像檔（`.dmg`）。

</Step>

<Step>

### 開啟磁碟映像檔

開啟下載完成的 `QuotaPulse.dmg`。

Finder 視窗中會顯示 QuotaPulse 應用程式與 Applications 資料夾的捷徑。

</Step>

<Step>

### 將 QuotaPulse 移至 Applications

將 **QuotaPulse** 拖曳到 **Applications（應用程式）** 資料夾。

</Step>

<Step>

### 開啟 QuotaPulse

從 **Applications（應用程式）** 資料夾開啟 **QuotaPulse**。

由於目前的 Beta 版本尚未完成 Apple Developer ID 公證，macOS 第一次啟動時可能會顯示安全性警告。

如果 macOS 阻擋 QuotaPulse，請參考[首次啟動指南](./first-launch.mdx)。

</Step>

</Steps>

## 已經在使用 QuotaPulse？

如果 QuotaPulse 已經安裝完成，而你想安裝較新的版本，請參考[更新指南](./updating.mdx)。

## 遇到問題？

如果安裝完成後 QuotaPulse 沒有按照預期運作，請參考[疑難排解](./troubleshooting.mdx)。
