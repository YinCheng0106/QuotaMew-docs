## 系統需求

安裝 QuotaMew 前，請確認你的 Mac 符合以下需求：

- macOS 14 或更新版本

<Callout type="warn" title="Release Candidate 版本">

QuotaMew v0.2.0 RC.1 目前以 Release Candidate 形式提供，使用 Apple Development 簽署，但尚未使用 Developer ID 簽署或完成公證（Notarization）。

因此，在你第一次開啟 QuotaMew 時，macOS 可能會顯示安全性警告。

請只從 QuotaMew 官方網站或 GitHub Repository 下載 QuotaMew。

</Callout>

## 安裝 QuotaMew

<Steps>

<Step>

### 下載 QuotaMew

從 [官方 v0.2.0 RC.1 Release](https://github.com/YinCheng0106/QuotaMew/releases/tag/v0.2.0-rc.1) 或 [QuotaMew 官方下載頁面](/zh-TW/download)取得 `QuotaMew-v0.2.0-rc.1.dmg`。

</Step>

<Step>

### 開啟磁碟映像檔

開啟下載完成的 `.dmg` 檔案。

Finder 視窗中會顯示 QuotaMew 應用程式與 Applications 資料夾的捷徑。

</Step>

<Step>

### 將 QuotaMew 移至 Applications

將 **QuotaMew** 拖曳到 **Applications（應用程式）** 資料夾。

</Step>

<Step>

### 開啟 QuotaMew

從 **Applications（應用程式）** 資料夾開啟 **QuotaMew**。

目前 Release Candidate 使用 Apple Development 簽署，但尚未使用 Developer ID 簽署或完成公證供公開散布，因此 macOS 第一次啟動時可能會顯示安全性警告；如果發生，請依照[首次啟動指南](./first-launch.mdx)處理。

如果 macOS 阻擋 QuotaMew，請參考[首次啟動指南](./first-launch.mdx)。

</Step>

</Steps>

## 已經在使用 QuotaMew？

如果 QuotaMew 已經安裝完成，而你想安裝較新的版本，請參考[更新指南](./updating.mdx)。

## 遇到問題？

如果安裝完成後 QuotaMew 沒有按照預期運作，請參考[疑難排解](./troubleshooting.mdx)。
