## 系統需求

安裝 QuotaMew 前，請確認你的 Mac 符合以下需求：

- <StableRequirements locale="zh-TW" />

<Callout type="warn" title="散布與簽署">

<StableReleaseName locale="zh-TW" />。<StableDistribution locale="zh-TW" />

因此，在你第一次開啟 QuotaMew 時，macOS 可能會顯示安全性警告。

請只從 QuotaMew 官方網站或 GitHub Repository 下載 QuotaMew。

</Callout>

## 安裝 QuotaMew

<Steps>

<Step>

### 下載 QuotaMew

從 <StableReleaseLink locale="zh-TW" /> 或 [QuotaMew 官方下載頁面](/zh-TW/download)取得 <StableReleaseDownload locale="zh-TW" />。

</Step>

<Step>

### 開啟磁碟映像檔

開啟下載完成的 `.dmg` 檔案。

Finder 視窗中會顯示 QuotaMew 應用程式與 Applications 資料夾的捷徑。

</Step>

<Step>

### 將 QuotaMew 移至 Applications

將 **QuotaMew** 拖曳到 **Applications（應用程式）** 資料夾。

</Step>

<Step>

### 開啟 QuotaMew

從 **Applications（應用程式）** 資料夾開啟 **QuotaMew**。

macOS 第一次啟動時可能會顯示安全性警告；如果發生，請依照[首次啟動指南](./first-launch.mdx)處理。

</Step>

</Steps>

## 準備 Provider

QuotaMew 不會替你安裝 Codex 或登入。請先查看 [Providers](./providers.mdx)，確認本機 runtime 與帳號前置需求。

## 更新既有安裝

如果 QuotaMew 已經安裝完成，而你想安裝較新的版本，請參考[更新指南](./updating.mdx)。

## 遇到問題？

如果安裝完成後 QuotaMew 沒有按照預期運作，請參考[疑難排解](./troubleshooting.mdx)。
