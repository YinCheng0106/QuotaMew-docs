QuotaMew lives in the macOS menu bar. Click its status item to open the dashboard; use the native right-click menu for **Refresh Now**, **Settings…**, and **Quit QuotaMew**.

## Menu Bar display

In **Single** mode, choose one quota to display: **5-hour**, **Weekly**, or **Luna Reserve**. In **Overview** mode, QuotaMew can show both regular windows together, for example `5H 86% · W 71%`.

- `5H` — 5-hour quota
- `W` — Weekly quota
- `R` — Luna Reserve

**Remaining** and **Used** are presentation modes. For example, Remaining may show `5H 86% · W 71%`, while Used may show `5H 14% · W 29%`. Switching them does not change provider quota data.

Luna Reserve is an additional quota bucket observed from Codex data and presented conservatively. You may select it explicitly in Single mode. In Overview mode it appears only when QuotaMew's conservative prominence rule allows it. QuotaMew does not control, activate, or guarantee Reserve routing.

The General settings screen controls how quota values are presented, which provider is pinned to the menu bar, and whether Single or Overview mode is used.

## Settings categories

Open **Settings…** from the status item's right-click menu.

| Category | Controls |
| --- | --- |
| General | Launch at Login, Show Menu Bar Item, Remaining / Used, Menu Bar Provider, Single / Overview, Single-mode quota selection, replay onboarding, Diagnostics |
| Providers | Enable or disable Codex and the Experimental / Unverified Claude reader |
| Notifications | Enable reset notifications, request permission, and choose reminder times |

**Automatic** chooses a provider with renderable quota data. Pinning a provider keeps that choice even if it becomes disabled or unavailable; it does not silently switch to another provider. If a selected quota is missing, its value is shown as a dash rather than substituted with another quota.

Display choices update the presentation without requiring a provider refresh. Provider enablement, pinning, display mode, selected quota, notification preferences and onboarding state persist locally across launches. Launch at Login is managed by macOS; if approval is required, follow the message in Settings and check **System Settings → General → Login Items**.

Background refresh is every 15 minutes while the app is running; use **Refresh Now** when you need a new reading. A countdown changing does not mean quota data was fetched again.

## Onboarding

The first-run onboarding briefly explains provider status, privacy, quota presentation, provider preference, Launch at Login, and optional notifications. It is not an account-creation or provider-installation wizard. You can replay onboarding from Settings.

Notification permission is requested only after you explicitly choose the notification action. Notifications are optional and are delivered locally by macOS.

## Notifications and reset reminders

In **Settings → Notifications**, turn on **Enable reset notifications** and grant macOS permission when requested. Routine refreshes do not open a permission prompt. If permission was denied, enable QuotaMew in **System Settings → Notifications**.

- For short windows (up to 6 hours), select **1-hour** and/or **30-minute** reminders.
- For long windows, select **24-hour**, **6-hour** and/or **1-hour** reminders.
- A reminder can tell you a reset is approaching or that significant quota remains before reset. QuotaMew can also notify when new provider data supports detecting a completed reset.
- Luna Reserve is informational and does not generate reset reminders or completed-reset notifications.

Notifications depend on fresh, supported quota data and valid reset information. A countdown reaching zero alone does not prove the provider reset. Repeated refreshes are deduplicated using bounded local state, so the same reminder is not repeatedly sent for one quota cycle.

QuotaMew must be running to evaluate new data. Sleep, unavailable quota, disabled providers, notification permissions and macOS Focus or notification settings can affect timing or visibility. Delivery is not guaranteed, and missed thresholds are not a promise of catch-up notifications.

See [Notifications do not appear](./troubleshooting.mdx#notifications-do-not-appear) for safe checks and [Privacy](./privacy.mdx) for local-state details.
