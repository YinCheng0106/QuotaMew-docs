QuotaPulse Beta is currently distributed without Apple Developer ID signing and notarization.

Because of this, macOS may block QuotaPulse the first time you open it.

<Callout type="warn" title="Only continue if you trust the download source">

Only download QuotaPulse from the official QuotaPulse website or GitHub repository.

Do not disable macOS security features globally.

</Callout>

## Open QuotaPulse for the first time

<Steps>

<Step>

### Try to open QuotaPulse

Open **Applications** and launch **QuotaPulse**.

macOS may display a warning and prevent the app from opening.

</Step>

<Step>

### Open Privacy & Security

Open **System Settings** and select **Privacy & Security**.

</Step>

<Step>

### Find the QuotaPulse security message

Scroll to the **Security** section.

You should see a message indicating that QuotaPulse was blocked from use.

</Step>

<Step>

### Select Open Anyway

Select **Open Anyway** next to the QuotaPulse message.

macOS may ask you to authenticate with Touch ID or your password.

</Step>

<Step>

### Confirm Open

Confirm that you want to open QuotaPulse.

After approval, macOS should allow the installed copy of QuotaPulse to launch.

</Step>

</Steps>

## What happens next?

QuotaPulse runs as a macOS menu bar app.

After opening it successfully, look for the QuotaPulse icon in your menu bar.
