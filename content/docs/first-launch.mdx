QuotaMew Beta is currently distributed without Apple Developer ID signing and notarization.

Because of this, macOS may block QuotaMew the first time you open it.

<Callout type="warn" title="Only continue if you trust the download source">

Only download QuotaMew from the official QuotaMew website or GitHub repository.

Do not disable macOS security features globally.

</Callout>

## Open QuotaMew for the first time

<Steps>

<Step>

### Try to open QuotaMew

Open **Applications** and launch **QuotaMew**.

macOS may display a warning and prevent the app from opening.

</Step>

<Step>

### Open Privacy & Security

Open **System Settings** and select **Privacy & Security**.

</Step>

<Step>

### Find the QuotaMew security message

Scroll to the **Security** section.

You should see a message indicating that QuotaMew was blocked from use.

</Step>

<Step>

### Select Open Anyway

Select **Open Anyway** next to the QuotaMew message.

macOS may ask you to authenticate with Touch ID or your password.

</Step>

<Step>

### Confirm Open

Confirm that you want to open QuotaMew.

After approval, macOS should allow the installed copy of QuotaMew to launch.

</Step>

</Steps>

## What happens next?

QuotaMew runs as a macOS menu bar app.

After opening it successfully, look for the QuotaMew icon in your menu bar.

On first launch, the native onboarding explains provider status, privacy, quota presentation, menu bar provider choice, and Launch at Login. It does not create an account or install a provider.
