QuotaMew 目前尚未提供自動更新功能。

若要安裝較新的版本，請下載最新的磁碟映像檔，並取代目前已安裝的 QuotaMew 應用程式。

<Callout type="info" title="你的設定通常會保留下來">

取代 QuotaMew 應用程式本身，通常不會移除你既有的設定。

更新前不需要先解除安裝舊版本。

</Callout>

## 更新 QuotaMew

<Steps>

<Step>

### 結束 QuotaMew

更新前，請先結束目前正在執行的 QuotaMew。

這可以確保 macOS 能正確取代應用程式。

</Step>

<Step>

### 下載最新版本

從 QuotaMew 官方網站或 GitHub Releases 下載最新的 QuotaMew `.dmg`。

</Step>

<Step>

### 開啟磁碟映像檔

開啟剛下載的 QuotaMew 磁碟映像檔。

</Step>

<Step>

### 將 QuotaMew 移至 Applications

將 **QuotaMew** 拖曳到 **Applications（應用程式）** 資料夾。

因為你的 Mac 已經安裝 QuotaMew，Finder 應該會詢問你是否要取代現有的應用程式。

</Step>

<Step>

### 取代現有版本

當 Finder 詢問你要進行什麼操作時，選擇 **取代**。

這會取代 QuotaMew 應用程式本身，而通常不會移除你已儲存的偏好設定。

</Step>

<Step>

### 重新開啟 QuotaMew

再次從 Applications 資料夾開啟 QuotaMew。

確認目前執行的是你預期的新版本，並檢查原本的設定是否仍然存在。

</Step>

</Steps>

## macOS 再次顯示安全性警告

由於目前的 Beta 版本尚未使用 Apple Developer ID 完成簽署與公證，安裝較新的版本後，macOS 可能會再次進行安全性檢查。

如果 macOS 阻擋 QuotaMew，請參考[首次啟動指南](./first-launch.mdx)。
