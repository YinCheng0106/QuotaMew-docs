QuotaPulse Beta 目前尚未使用 Apple Developer ID 完成簽署與公證（Notarization）。

因此，macOS 可能會在你第一次開啟 QuotaPulse 時阻擋應用程式。

<Callout type="warn" title="請確認你信任下載來源">

請只從 QuotaPulse 官方網站或 GitHub Repository 下載 QuotaPulse。

請勿停用 macOS 的全域安全性機制。

</Callout>

## 第一次開啟 QuotaPulse

<Steps>

<Step>

### 嘗試開啟 QuotaPulse

開啟 **Applications（應用程式）** 資料夾並啟動 **QuotaPulse**。

macOS 可能會顯示安全性警告，並暫時阻止應用程式開啟。

</Step>

<Step>

### 開啟「隱私權與安全性」

開啟 **系統設定**，並選擇 **隱私權與安全性**。

</Step>

<Step>

### 找到 QuotaPulse 的安全性訊息

向下捲動至 **安全性** 區段。

你應該會看到一則訊息，表示 QuotaPulse 已被 macOS 阻擋。

</Step>

<Step>

### 選擇「仍要打開」

在 QuotaPulse 的安全性訊息旁選擇 **仍要打開**。

macOS 可能會要求你使用 Touch ID 或密碼進行驗證。

</Step>

<Step>

### 確認開啟

確認你要開啟 QuotaPulse。

完成核准後，macOS 應該就會允許目前安裝的 QuotaPulse 啟動。

</Step>

</Steps>

## 接下來會發生什麼？

QuotaPulse 是一款 macOS 選單列應用程式。

成功啟動後，請在 macOS 選單列中尋找 QuotaPulse 圖示。

如果 QuotaPulse 沒有出現在選單列，可以查看[疑難排解](./troubleshooting.mdx)。
