QuotaMew Beta 目前尚未使用 Apple Developer ID 完成簽署與公證（Notarization）。

因此，macOS 可能會在你第一次開啟 QuotaMew 時阻擋應用程式。

<Callout type="warn" title="請確認你信任下載來源">

請只從 QuotaMew 官方網站或 GitHub Repository 下載 QuotaMew。

請勿停用 macOS 的全域安全性機制。

</Callout>

## 第一次開啟 QuotaMew

<Steps>

<Step>

### 嘗試開啟 QuotaMew

開啟 **Applications（應用程式）** 資料夾並啟動 **QuotaMew**。

macOS 可能會顯示安全性警告，並暫時阻止應用程式開啟。

</Step>

<Step>

### 開啟「隱私權與安全性」

開啟 **系統設定**，並選擇 **隱私權與安全性**。

</Step>

<Step>

### 找到 QuotaMew 的安全性訊息

向下捲動至 **安全性** 區段。

你應該會看到一則訊息，表示 QuotaMew 已被 macOS 阻擋。

</Step>

<Step>

### 選擇「仍要打開」

在 QuotaMew 的安全性訊息旁選擇 **仍要打開**。

macOS 可能會要求你使用 Touch ID 或密碼進行驗證。

</Step>

<Step>

### 確認開啟

確認你要開啟 QuotaMew。

完成核准後，macOS 應該就會允許目前安裝的 QuotaMew 啟動。

</Step>

</Steps>

## 接下來會發生什麼？

QuotaMew 是一款 macOS 選單列應用程式。

成功啟動後，請在 macOS 選單列中尋找 QuotaMew 圖示。

首次啟動時，原生 Onboarding 會介紹 Provider 狀態、隱私、額度呈現、選單列 Provider 選擇與登入時啟動。它不會建立帳號或安裝 Provider。

![QuotaMew Onboarding 顯示 Provider 狀態、隱私資訊、顯示偏好與登入時啟動](/images/screenshots/quotamew-onboarding.png)

如果 QuotaMew 沒有出現在選單列，可以查看[疑難排解](./troubleshooting.mdx)。
