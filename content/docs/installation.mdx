## Requirements

Before installing QuotaPulse, make sure your Mac meets the following requirements.

- macOS 14 or later

<Callout type="warn" title="Beta distribution">

QuotaPulse is currently distributed as a beta and is not yet signed and notarized with an Apple Developer ID.

Because of this, macOS may display a security warning when you open QuotaPulse for the first time.

</Callout>

## Install QuotaPulse

<Steps>

<Step>

### Download QuotaPulse

Download the latest QuotaPulse disk image (`.dmg`) from the [official download page](/download).

</Step>

<Step>

### Open the disk image 

Open the downloaded `QuotaPulse.dmg` file.

A Finder window containing QuotaPulse and an Applications shortcut will appear.

</Step>

<Step>

### Move QuotaPulse to Applications

Drag **QuotaPulse** into the **Applications** folder.

</Step>

<Step>

### Open QuotaPulse

Open **QuotaPulse** from your Applications folder.

Because the current beta is not yet notarized by Apple, macOS may display a security warning on first launch.

If macOS blocks QuotaPulse, continue with the [First Launch guide](./first-launch.mdx).

</Step>

</Steps>
