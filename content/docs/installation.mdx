## Install QuotaMew

<Steps>

<Step>

### Download QuotaMew

Download <StableReleaseDownload locale="en" /> from the <StableReleaseLink locale="en" /> or the [official download page](/download).

</Step>

<Step>

### Open the disk image 

Open the downloaded `.dmg` file.

A Finder window containing QuotaMew and an Applications shortcut will appear.

</Step>

<Step>

### Move QuotaMew to Applications

Drag **QuotaMew** into the **Applications** folder.

</Step>

<Step>

### Open QuotaMew

Open **QuotaMew** from your Applications folder.

macOS may display a security warning on first launch; follow the [First Launch guide](./first-launch.mdx) if it does.

</Step>

</Steps>
