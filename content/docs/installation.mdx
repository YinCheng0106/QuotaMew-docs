## Requirements

Before installing QuotaMew, make sure your Mac meets the following requirements.

- macOS 14 or later

<Callout type="warn" title="Release Candidate distribution">

QuotaMew v0.2.0 RC.1 is distributed as a Release Candidate. It is Apple Development signed, but not Developer ID signed or notarized.

Because of this, macOS may display a security warning when you open QuotaMew for the first time.

</Callout>

## Install QuotaMew

<Steps>

<Step>

### Download QuotaMew

Download `QuotaMew-v0.2.0-rc.1.dmg` from the [official v0.2.0 RC.1 release](https://github.com/YinCheng0106/QuotaMew/releases/tag/v0.2.0-rc.1) or the [official download page](/download).

</Step>

<Step>

### Open the disk image 

Open the downloaded `.dmg` file.

A Finder window containing QuotaMew and an Applications shortcut will appear.

</Step>

<Step>

### Move QuotaMew to Applications

Drag **QuotaMew** into the **Applications** folder.

</Step>

<Step>

### Open QuotaMew

Open **QuotaMew** from your Applications folder.

The current Release Candidate is Apple Development signed, but it is not Developer ID signed or notarized for public distribution. macOS may display a security warning on first launch; follow the [First Launch guide](./first-launch.mdx) if it does.

If macOS blocks QuotaMew, continue with the [First Launch guide](./first-launch.mdx).

</Step>

</Steps>
