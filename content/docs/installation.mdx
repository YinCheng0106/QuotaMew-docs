## Requirements

Before installing QuotaMew, make sure your Mac meets the following requirements.

- macOS 14 or later

<Callout type="warn" title="Beta distribution">

QuotaMew is currently distributed as a beta and is not yet signed and notarized with an Apple Developer ID.

Because of this, macOS may display a security warning when you open QuotaMew for the first time.

</Callout>

## Install QuotaMew

<Steps>

<Step>

### Download QuotaMew

Download `QuotaMew-v0.2.0-beta.3.dmg` from the [official Beta 3 release](https://github.com/YinCheng0106/QuotaMew/releases/tag/v0.2.0-beta.3) or the [official download page](/download).

</Step>

<Step>

### Open the disk image 

Open the downloaded `.dmg` file.

A Finder window containing QuotaMew and an Applications shortcut will appear.

</Step>

<Step>

### Move QuotaMew to Applications

Drag **QuotaMew** into the **Applications** folder.

</Step>

<Step>

### Open QuotaMew

Open **QuotaMew** from your Applications folder.

The current beta is Apple Development signed, but it is not Developer ID signed or notarized for public distribution. macOS may display a security warning on first launch; follow the [First Launch guide](./first-launch.mdx) if it does.

If macOS blocks QuotaMew, continue with the [First Launch guide](./first-launch.mdx).

</Step>

</Steps>
